### Bullet 1

> Modeled UK day-ahead electricity spot prices on half-hourly data using lagged demand,
> weather and seasonality features, cutting forecast error by 18% against a seasonal naive
> baseline under walk-forward validation.

| Sub-claim | Proof | Status |
|---|---|---|
| UK day-ahead prices, half-hourly | `src/ppa/ingest/elexon.py` — Elexon MID, `APXMIDP`, 48 periods/day | UNVERIFIED |
| Lagged demand features | `src/ppa/features/build.py` — NESO `ND`/`TSD`, residual load = demand − embedded wind − embedded solar | UNVERIFIED |
| Weather features | `src/ppa/ingest/openmeteo.py` — temperature, wind speed, radiation at 6 GB sites | UNVERIFIED |
| Seasonality features | `src/ppa/features/build.py` — Fourier terms on period-of-day, day-of-week, day-of-year; holiday flags | UNVERIFIED |
| Seasonal naive baseline | `src/ppa/models/naive.py` — the baseline is stated explicitly, not chosen after the fact | UNVERIFIED |
| Walk-forward validation | `src/ppa/models/walkforward.py` — expanding window, periodic refit, 1-day-ahead horizon | UNVERIFIED |
| **18% error reduction** | `reports/metrics.json → forecast.mae_improvement_vs_naive` | UNVERIFIED — **measured value goes here** |
| No look-ahead | `tests/test_no_leakage.py` — every feature's source timestamp ≤ gate closure | UNVERIFIED |

**Reproduce:** `make all` then `jq '.forecast' reports/metrics.json`

## Questions an interviewer will ask, and where the answer lives

| Question | Answer |
|---|---|
| "Is this actually day-ahead, or are you peeking?" | `tests/test_no_leakage.py`; gate closure defined once in `config.py` |
| "What baseline? Seasonal naive can mean five things." | Lesson 06 defines the variants and states which one the headline number uses |
| "48 periods a day?" | Lesson 03 and `tests/test_calendar.py` — 46/48/50, BST transitions |
| "Does the edge survive costs?" | `metrics.json → strategy` includes a zero-cost and a with-cost run side by side |
| "Does it work outside the gas crisis?" | `metrics.json → strategy.by_regime` |
| "Is the Sharpe significant?" | Bootstrap CI in `src/ppa/strategy/risk.py`, reported alongside the point estimate |
| "Could you actually trade this?" | Lesson 11 states the instrument and the assumptions honestly, including what it does *not* model (physical delivery, credit, imbalance exposure) |
